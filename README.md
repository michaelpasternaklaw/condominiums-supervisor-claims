# אתר מאגר הפסיקה ל-GitHub Pages

אתר סטטי בעברית לחיפוש, סינון, צפייה והורדת פסקי הדין שבמאגר המקומי.

## עדכון האתר

לאחר עדכון מאגר הפסיקה, מריצים משורש הפרויקט:

```bash
python3 legal_library/case_law/build_case_law_repository.py --no-progress
python3 legal_library/case_law/github-pages/build_site.py
```

הסקריפט יוצר בתוך `dist/`:

- קטלוג מטא-דאטה לחיפוש מהיר;
- אינדקס טקסט מלא המחולק למקטעים;
- עותק יחיד מכל PDF ייחודי;
- עותק טקסט של כל מסמך.

## פרסום

התיקייה מוכנה לשמש כמאגר Git עצמאי. תהליך GitHub Actions המצורף מפרסם את `dist/` ל-GitHub Pages בכל דחיפה לענף `main`.

ב-GitHub יש לבחור ב-Settings → Pages → Source: **GitHub Actions**.

## פרטיות ומעמד משפטי

GitHub Pages הוא אתר אינטרנט נגיש לציבור, אלא אם חשבון GitHub וההגדרות מאפשרים אתר Pages פרטי. פסקי הדין כוללים שמות ולעיתים פרטים מזהים נוספים. לפני פרסום יש לוודא שפרסום מחדש של הקורפוס מתאים לצורך ולמדיניות הפרטיות הרצויה.

חומרי העבודה הפרטיים אינם חלק מהאתר. תהליך הבנייה מקבל מסמכים רק מתיקיות המקור הציבוריות של מאגר הפסיקה, ובנוסף עוצר את הפרסום אם הוא מזהה תוכן פרטי במטא-דאטה או בטקסט שיועדו לאתר.

האתר הוא כלי מחקר ואינו מאגר משפטי מוסמך. יש לבדוק נוסח מלא, ערעורים, ביטול ושינויים בדין לפני הסתמכות.
