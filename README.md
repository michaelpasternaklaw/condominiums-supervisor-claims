# אתר מאגר הפסיקה ל-GitHub Pages

אתר סטטי בעברית לחיפוש, דירוג והשוואת פסיקה ולבניית חבילת טיעון מקומית ומוצפנת. האתר מציג את מלוא אינדקס הפסיקה הציבורי ואת הטקסט של כל PDF זמין. במסמכים סרוקים בלבד נעשה OCR מקומי והם מסומנים בהתאם.

## יכולות

- חיפוש מטא־דאטה בכל הרשומות וחיפוש טקסט מלא לפי מקטעי מונחים ועמודים;
- דירוג שמעדיף מעמד מקור ואימות לפני דמיון עובדתי, עם חיזוק לזיקה לאשדוד;
- מיקודי נושא דו־שלביים: ברירת מחדל מחמירה של ראיה חזקה בהכרעה, אפשרות להרחבה לדיון משני ומיקוד משנה לפי סוג העוגן; בכלל זה מזגן/רעש/רטט/חום, מים וניקוז, מצלמות/פרטיות/האזנת סתר, שימוש וחזקה ייחודיים, סילוק יד, גגונים, יונים, סמכות ומניעת כפל;
- מסך “פסיקה חשובה” המציג אסמכתאות מרכזיות מתוך החלטות המפקחים, מאוחד לפי סוג ומספר הליך ועם החלטה מצטטת, עמוד וקטע ראיה;
- סינון לפי לשכה, עיר, מפקח/ת, נושא, שנה, סוג, מקור וזמינות טקסט;
- הורדת עותק Word עריך לכל החלטה שיש לה טקסט מלא, תוך שמירת גבולות עמודי המקור;
- השוואה של עד ארבע החלטות;
- סיווג מבוסס כללים של נושאים, טענות הגנה, עקרונות, תוצאות וסעדים, לרבות עמודי איתור;
- סביבת תיק מוצפנת בדפדפן, ציטוטים עם עמוד וייצוא Word/PDF/גיבוי;
- חסימת פרסום של חומרי התיק הפרטיים וסריקת פרטיות בכל בנייה.

## עדכון האתר

לאחר עדכון מאגר הפסיקה, מריצים מתיקיית אתר GitHub Pages:

```bash
python3 tools/legal_pipeline.py all
python3 tools/refine_focus.py
python3 tools/export_docx.py
python3 tools/build_precedents_index.py
python3 tools/check_precedents_index.py ../../../outputs/legal_decisions_database/precedents
python3 build_site.py
node tests/smoke.mjs
```

הפקודה הראשונה בונה מסד SQLite מקומי, מחלקת את המסמכים לעמודים ולמקטעים משפטיים, מסווגת אותם בכללים דטרמיניסטיים, מכינה שאילתות מחקר ומייצאת חוזה ציבורי מצומצם. `refine_focus.py` מפעיל שכבת מיקוד מחמירה על חלונות קצרים סביב עוגנים משפטיים; הוא דורש הקשר תומך, נותן משקל גבוה לדיון ולהכרעה ומפיק קטעי ראיה קצרים עם עמוד. המסד, תוצאות הביניים ומדגם הבדיקה נשארים בתיקיית `repository/` שמחוץ למאגר האתר.

`build_precedents_index.py` סורק מקומית את הטקסט שכבר חולץ, מאחד וריאציות כתיב של מספרי הליכים, מסיר אזכורים עצמיים ומדרג אסמכתאות לפי מספר החלטות מפקח מצטטות, ערכאה, שימוש בדיון או בקביעה והתאמה לנושאי בתים משותפים. כברירת מחדל הוא אינו מקבל מספר תיק שאין לפניו סוג הליך, כדי להעדיף דיוק על פני כיסוי. לכל אסמכתה נשמרים תיק המקור, העמוד וקטע הראיה, אך בדירוג נשמר מקור אחד מיטבי לכל החלטה מצטטת כדי למנוע כפל. התוצרים המקומיים נמצאים ב־`outputs/legal_decisions_database/precedents/` וכוללים את האינדקס המלא וכן `precedents_focus.csv` ו־`precedents_focus.json` לפרסום ממוקד, לצד SQLite עם FTS5 וקובץ Excel. הסריקה אינה מבצעת בקשות רשת ואינה שולחת טקסט למודל.

אפשר להריץ כל שלב בנפרד באמצעות `ingest`, `classify`, `research`, `evaluate` או `export`. כללי הסיווג הכלליים נמצאים ב־`config/classification_rules.json`, וכללי המיקוד המחמירים ב־`config/focus_rules.json`. דוח ההערכה לא יציג עמידה ביעדי הדיוק עד שמדגם הזהב נבדק וסומן ידנית.

הסקריפט יוצר בתוך `dist/`:

- קטלוג מטא־דאטה הממוזג מן האינדקס הארצי, הכפילויות ואינדקס אשדוד;
- אינדקס טקסט מלא המחולק לפי מונחים ועמודים, כך שלא נדרשת טעינה של כל הקורפוס;
- מקטעי ראיה וסיווג נפרדים, עם הבחנה בין טענת צד, דיון וקביעה;
- עותק יחיד מכל PDF ייחודי;
- עותק DOCX תקין לכל מסמך בעל טקסט מלא; העותק מסומן כהמרה אוטומטית ואינו מוצג כמסמך רשמי;
- עותק יחיד של הטקסט בתוך מקטעי העמודים, ללא שכפול בקובצי טקסט נפרדים.

הבנייה נעשית בתיקיית staging ומחליפה את `dist/` רק לאחר סריקת פרטיות ותקינות. היא נעצרת אם האתר גדול מ־850MB, אם קובץ יחיד גדול מ־90MB או אם נמצא hard link. מסמך מלא שלא ניתן להכניס בתקציב הגודל נשאר מוצג ומקושר לעותק הציבורי הרשמי.

## פרסום

התיקייה מוכנה לשמש כמאגר Git עצמאי. תהליך GitHub Actions המצורף מאמת ומפרסם את `dist/` ל-GitHub Pages בכל דחיפה לענף `main`. עבודת החילוץ והסיווג הכבדה נעשית מקומית ואינה רצה ב־GitHub Actions.

ב-GitHub יש לבחור ב-Settings → Pages → Source: **GitHub Actions**.

## פרטיות ומעמד משפטי

GitHub Pages הוא אתר אינטרנט נגיש לציבור, אלא אם חשבון GitHub וההגדרות מאפשרים אתר Pages פרטי. פסקי הדין כוללים שמות ולעיתים פרטים מזהים נוספים. לפני פרסום יש לוודא שפרסום מחדש של הקורפוס מתאים לצורך ולמדיניות הפרטיות הרצויה.

חומרי העבודה הפרטיים אינם חלק מהאתר. סביבת התיק מוצפנת באמצעות AES-GCM ונשמרת רק בדפדפן. קובץ האתחול הפרטי נמצא מחוץ למאגר האתר, מיובא ידנית, ומוצפן מיד לאחר הייבוא. תהליך הבנייה מקבל מסמכים רק מתיקיות המקור הציבוריות ועוצר את הפרסום אם הוא מזהה תוכן פרטי בתוצר.

האתר הוא כלי מחקר ואינו מאגר משפטי מוסמך. קובצי ה־Word הם עותקים עריכים שנוצרו מן הטקסט שחולץ; יש לאמת כל ציטוט ומספר עמוד מול ה־PDF, ולבדוק נוסח מלא, ערעורים, ביטול ושינויים בדין לפני הסתמכות.
